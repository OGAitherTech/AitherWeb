# Aither Web

Aither Web is a fast, clean, responsive web launchpad for the Aither project family. It is designed to work on iPhone, iPad, and desktop browsers and can be hosted directly with GitHub Pages.

## v1

- Aither Web branded start page
- Web search from the main search box
- Address bar that accepts URLs or search queries
- DuckDuckGo, Google, and Bing search options
- Quick links for common websites
- Add and remove personal bookmarks
- Local browsing/search history
- Dark, light, and system themes
- Open links in the current page or a new tab
- Responsive mobile layout with a slide-out sidebar
- Settings panel
- LocalStorage persistence
- No backend or build step required

## Files

- `index.html` — application structure
- `style.css` — responsive Aither Web interface
- `app.js` — search, bookmarks, history, themes, and settings

## GitHub Pages

The project is a static website, so it can be published with GitHub Pages using the `main` branch and the repository root (`/`).

## Privacy

Aither Web stores bookmarks, settings, and local history in the browser's LocalStorage. Searches are sent directly to the search engine selected by the user when a search is performed.

## Roadmap

Future versions can add tabs, a real browser shell where platform APIs allow it, customizable quick-link layouts, import/export, keyboard shortcuts, and additional Aither integrations.
